# Walk Chicago

Audio walking tours of Chicago: 22 tours and 144 GPS-triggered stops, about 6 hours of narration on storied companies and industries, famous events and people, architecture, and the lakefront parks, from the Loop and the river to Uptown, Pilsen, Hyde Park, Pullman and Oak Park. Each stop is getting optional "Go deeper" chapters with about twice as much again.

- **Use it:** https://walk-chicago.pages.dev (after the first ship; Safari on iPhone, Add to Home Screen), or the Walk Chicago iPhone app in TestFlight
- **Sister app:** [Walk NYC](https://github.com/apolitakis/walk-nyc), whose code this started from
- **How it's put together, and how to change it:** see [CLAUDE.md](CLAUDE.md), [SHIPPING.md](SHIPPING.md), [voices/README.md](voices/README.md), [ios/TESTFLIGHT.md](ios/TESTFLIGHT.md)
